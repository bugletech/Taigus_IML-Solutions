# Code of Conduct

## Our Commitment

[Bugle Technologies](https://www.bugle.in) is committed to maintaining a respectful, professional, and collaborative environment across our projects.

This repository may include work from maintainers, contributors, team members, reviewers, and project stakeholders. Everyone participating in this project is expected to communicate respectfully and contribute in a constructive manner.

## Expected Behavior

Examples of expected behavior include:

- Communicating respectfully and professionally
- Giving clear and constructive feedback
- Focusing on the work, not personal criticism
- Being open to suggestions and improvements
- Helping others understand issues or changes
- Respecting different opinions, approaches, and experience levels
- Keeping project discussions relevant and productive

## Unacceptable Behavior

Examples of unacceptable behavior include:

- Insults, harassment, or personal attacks
- Disrespectful, aggressive, or threatening comments
- Discrimination or offensive language
- Trolling or intentionally disruptive behavior
- Sharing private or confidential information without permission
- Repeatedly ignoring maintainer or project guidelines
- Any behavior that makes the project environment unsafe or unprofessional

## Scope

This Code of Conduct applies to all project-related spaces, including:

- GitHub issues
- Pull requests
- Discussions
- Code reviews
- Project documentation
- GitHub Pages previews
- Project-related communication channels

It also applies when someone is representing Bugle Technologies or this project in a professional context.

## Reporting Issues

If you notice behavior that violates this Code of Conduct, please report it to the project maintainer or Bugle Technologies contact person.

Contact:

```text
apps@bugletech.com
```

When reporting an issue, please include relevant details such as:

- What happened
- Where it happened
- Who was involved
- Links, screenshots, or messages if available

Reports will be reviewed privately, respectfully, and fairly.

## Enforcement

Project maintainers may take appropriate action depending on the situation.

This may include:

- Giving a warning
- Removing inappropriate comments or content
- Limiting participation in the project
- Temporarily removing repository access
- Permanently removing repository access

Enforcement decisions should be fair, consistent, and focused on maintaining a respectful and productive project environment.

## Maintainer Responsibilities

Maintainers are responsible for:

- Making project expectations clear
- Reviewing reports seriously
- Protecting the privacy of reporters
- Taking action when needed
- Applying these rules fairly to all participants
- Maintaining a professional environment for collaboration

## Goal

The goal of this Code of Conduct is to support a professional and respectful environment where contributors, maintainers, team members, clients, and stakeholders can collaborate effectively.

Thank you for helping keep [BugleTech](https://github.com/bugletech) projects respectful, productive, and welcoming.
