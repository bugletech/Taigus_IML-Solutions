# Taigus IML Solutions - Website Design Preview

This repository contains static **HTML, CSS, JavaScript, and design assets** created by [BugleTech](https://github.com/bugletech) for the Taigus IML Solutions website design preview.

The final website is planned to be implemented in **WordPress**. This repository is used only to present front-end design previews for internal review, client feedback, and design approval before WordPress development.

## Live Preview

GitHub Pages preview, if enabled:

```text
https://bugletech.github.io/Taigus_IML-Solutions/
```

## Project Purpose

This repository helps Bugle Technologies, project stakeholders, and the client review:

- Page layout and structure
- Visual design direction
- Navigation flow
- Content placement
- UI styling
- Responsive design concepts
- Static page versions before WordPress implementation

This repository is **not a complete production website**.

## Important Notes

This repository does **not** include:

- WordPress theme files
- Backend code
- CMS setup
- WordPress plugins
- Database content
- Dynamic functionality
- Production deployment configuration

It includes only static preview files such as:

- HTML files
- CSS files
- JavaScript for basic UI interactions, if required
- Images, icons, fonts, and other design assets
- Static page layouts for review

## How to View Locally

1. Clone the repository.
2. Open the required HTML file from the `designs/` folder in a browser.
3. Review the layout on desktop and mobile screen sizes.

Example local files:

```text
Homepage: designs/Homepage/home-v1.html
Product Categories: designs/Products/product-categories.html
```
